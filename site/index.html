Patch Voice PE

Turns a Home Assistant Voice Preview Edition into a voice device for Patch. Use Chrome or Edge on a computer, and connect the Voice PE with a USB-C cable.

This browser can't talk to USB devices. Use Chrome or Edge on a computer.

1. Install the firmware

Replaces whatever is on the device. Skip this if it already runs Patch Voice PE.

2. Connect it to Wi-Fi and Patch

In Patch, open Settings → Voice → Voice devices → Add device, and copy the server address and token it shows.

The device restarts and connects. The light ring turns off when it is ready; say "Hey Jarvis" to talk.

Updates

The device installs new releases by itself. To push a build yourself, from any machine on the same network: 

curl -H "Authorization: Bearer <device token>" --data-binary @patch-voice-pe.bin http://patch-voice-XXXXXX.local/update
